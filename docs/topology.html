管理与身份

浏览器Cloudflare Pages / GitHub Pages / 本地服务统一输入规范、会话与管理传输；顶栏显示当前账号。
Worker + 私有 D1密码校验、8 小时随机会话、角色与最新归属校验只保存会话摘要；旧账号必须换密。内部令牌不进入浏览器。
Git 权威配置channels.jsonGitHub SHA 冲突重读；配置成功后提交任务请求。R2 配置是公开下游副本。

新增 / 刷新请求 → Worker 请求表 → 本机执行器领取与事务去重

采集、事务与发布

YouTube Data API档案 + 上传列表 + 50 ID 批量统计新增先最近 50 条，再全量分页。未知指标不填零；本机每日硬预算 9000 units。
SQLite 唯一历史写源data/dashboard.sqliteWAL、600 权限、事务写入、稳定频道 ID、别名、任务状态。活进程租约覆盖采集与发布。
R2 公开发布变更头像 → 不可变频道分片 → 最后发布索引任何必要上传失败都不推进索引；成功之后才发布完成状态。

R2 小型索引 → 浏览器按需读取当前频道历史，不再首屏下载完整历史

恢复与调度

加密备份SQLite 一致性快照 → AES-256-GCM → R2密钥独立保存；下载到空目录，核对清单、完整性及计数，拒绝覆盖运行库。
本机 cronwatch 每 2 分钟 / daily 当前 09:30Git 同步锁不覆盖采集；发布另有活 PID 锁。实际时刻以 crontab 为准。
唯一页面源码index.html → 生成 web/index.html只同步小文件镜像；不复制 SQLite 或完整 YouTube 历史。双站支持相对模块路径。

频道历史仍是公开数据，成员筛选不提供数据保密。users.json、明文凭据、原始数据库及密钥均不得发布。公开 Git 旧历史无法撤回，必须更换曾公开的旧密码。
