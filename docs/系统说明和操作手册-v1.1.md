# 第一部分 · 系统说明

## 1. 项目简介

YouTube（53 个频道）+ TikTok 公开数据看板：订阅数、播放量、点赞趋势、频道档案，支持分组/标签管理与成员权限（admin / member）。

## 2. 访问入口

| 入口 | 地址 | 性质 |
|---|---|---|
| 主站 | `https://social-dashboard-9ya.pages.dev/` | Cloudflare Pages，Git push 自动构建，纯静态只读 |
| 备用站 | `https://blockchainshadow.github.io/social-dashboard/` | GitHub Pages，同读一份 R2 数据 |
| 本地管理端 | `http://127.0.0.1:8000/web/` | `node server.mjs`，唯一可写入口（增删账号、刷新） |

静态站首次打开需下载约 93MB 全量快照（约半分钟），属正常。admin 登录后点顶栏 `🌍 全员` 查看全部频道（默认只看名下）。

## 3. 架构总览

```
数据源 → 采集层（本机 Mac）→ 存储层（R2 主 / Git 次）→ 服务层 → 浏览器
```

可视化拓扑：`docs/topology.html`（双击用浏览器打开）。

### 3.1 数据源

* **YouTube**：频道页 `ytInitialData`（档案 + 首屏视频）→ innertube `browse` 翻页补全（普通视频 + Shorts）→ `watch` 页精确播放/点赞/时长 → RSS 校准发布时间。
* **TikTok**：页面内嵌 JSON 直抓 → 失败走 Jina Reader 渲染代理 → 再失败走 Playwright 无头 Chromium。受 WAF 限制，只能拿档案级（粉丝/获赞/头像），无视频级。

### 3.2 采集层（本机 Mac，cron 驱动）

| 任务 | 周期 | 脚本 | 行为 |
|---|---|---|---|
| watch | 每 2 分钟 | `scripts/watch-local.sh` | 只补采 `channels.json` 中尚无快照的新频道；空闲轮零提交 |
| daily | 每天 3:00 | `scripts/daily-local.sh` | 逐频道抓取，跑完统一推一次 R2；备份见 §8 |
| usage | 每小时 17 分 | `scripts/fetch-cf-usage.mjs` | GraphQL 拉 Cloudflare 用量 → `data/cf-usage.json`，下一轮 watch 顺带推 R2 |

互斥锁：`.fetch-lock/` 目录锁（15 分钟逃逸）。日志：`logs/`，三脚本启动时自检轮转（超 20MB 只留末尾 2000 行）。

核心脚本：`fetch-youtube.mjs`（抓取/合并/头像落地，SSRF 防护：仅 http(s)、15s 超时、拒收文本、限 3MB）、`fetch-tiktok.mjs`、`watch-new-channels.mjs`、`publish-r2.sh`（增量发布：四份 JSON 整体 hash，未变 0.2s 跳过；头像只传 git 感知的新增，`--full` 全传）、`sync-static.sh`（根目录 ↔ `web/` 镜像同步）。

运行环境：node v22（nvm 路径；脚本内自动解析，cron 极简 PATH 下可用）。认证见 §5。

### 3.3 存储层

* **R2（真数据源）**：bucket `social-dashboard-data`。keys：`data/youtube-history.json`（约 93MB）、`avatars/*.jpg`（54 个，约 5MB）、`channels.json`、`users.json`、`cf-usage.json`。公读经 `r2.dev` + CORS `GET,HEAD *`。v1.1 时点：0.096GB / 58 对象。
* **Git（代码+配置）**：`blockchainshadow/social-dashboard`，`main` 分支。93MB 快照与 `cf-usage.json` 已 ignore（本地文件保留）；提交只含配置/代码/头像/文档。`.git` 历史 2.4G（旧快照堆积，不重写；clone 慢请用 `--depth 1`）。`v1.0a` 为浮动快照标记。
* **本地（唯一写源头，不可删）**：`data/` 93M + `web/data/` 93M（双份镜像）、`avatars/` + `web/avatars/` 各 5M、`backups/`（§8）、`logs/`。R2/Git 全是下游副本；删本地 = 下轮 cron 用空历史覆盖 R2，真丢数据。

### 3.4 服务层

* **Cloudflare Pages（主）**：仓库 `social-dashboard`，接 GitHub 自动构建；无构建命令，输出目录 `/`；纯静态只读（无后端，`/api/*` 404 时前端自动进入静态模式）。
* **GitHub Pages（备）**：同一仓库 `main`/`/` legacy 构建；前端默认数据源已切 R2，故与主站内容一致。
* **本地 `server.mjs`**：`127.0.0.1:8000`，零依赖。`POST /api/channels`（加号）、`POST /api/refresh`（单频道刷新）、`DELETE /api/channels/{platform}/{handle}`、`POST /api/channel-meta`（备注/分组/标签）。绑定非回环地址必须设 `DASH_TOKEN`，否则拒绝启动。

Pages 单文件 25MiB 上限，是数据必须放 R2 的根本原因（93MB 放不上去）。

### 3.5 浏览器（三种模式）

* **A 本地服务**：`127.0.0.1:8000/web/`，`/api/health` 通 → 管理菜单可见。
* **B 静态站**：两个公网域名，管理菜单自动隐藏；分组/标签/owner 由 R2 的 `channels.json` 补充（`staticMode || DATA_BASE` 条件）。
* **C 调试覆盖**：`?data=<R2地址>` 临时切源；`localStorage dash-data-base` 持久覆盖；默认 `window.DATA_BASE_URL` 即 R2 公读。

顶栏 `☁️` 徽标：读 R2 `cf-usage.json`，显示 `存储占比% · 对象数 · $账单`（悬停看 GB 明细与 A/B 类）；任一维度超 80% 黄、超 90% 红；文件缺失自动隐藏。

## 4. 费用与额度（v1.1 时点）

免费版：R2 存储 10GB / A 类 100 万 / B 类 1000 万 / 月、流出免费；Workers 日 10 万次；Pages 月 500 构建。

当前用量：R2 0.096GB（0.96%）/ 58 对象 / 30 天 A≈274 B≈231 / Workers 24h≈8 请求 / 预估 $0.003 / 账单 $0。

风险排序：① r2.dev 公网限速（访问量起来先换自定义域）② 93MB 首屏下载（再往后拆包：`summary.json` + 按频道懒加载）③ LFS 已否决（93MB 日更约 10 天烧穿 1GB 配额）。

## 5. 密钥面

* 前端零密钥；R2 公读无密钥。
* **cron 认证（持久）**：`~/.config/social-dashboard/cloudflare-api-token`（600 权限，不进仓库），custom token 同时含 `Workers R2 Storage / Edit` + `Account Analytics / Read`，No expiration。`publish-r2.sh` 与 `fetch-cf-usage.mjs` 优先读它。
* **过渡回退**：本机 wrangler OAuth（`wrangler login`，数小时过期，cron 下无法刷新，仅应急手动用）。
* `gh` 凭证走系统钥匙串；远端开 `server.mjs` 必须设 `DASH_TOKEN`。

# 第二部分 · 操作手册

## 6. 日常查看

1. 打开主站（或备用站），等全量快照载入（首次约半分钟）。
2. admin 点 `🌍 全员` 看全部；分组/标签下拉筛选；7/28/90 天/终身切换；`⬇ CSV` 导出；`⟳ 数据刷新` 重载。
3. 顶栏 `☁️` 徽标悬停看用量明细（绿色正常，黄色超 80%，红色超 90%）。

## 7. 账号管理（必须走本地端）

1. 起服务：`node server.mjs` → `http://127.0.0.1:8000/web/`。
2. `👤 +/-` → `➕ 添加账号`（填 handle/链接/频道 ID，可勾全量）→ 先验证再入库。
3. `✏️ 分组/标签`（仅 owner 或 admin 全员模式）→ 保存后约 1 分钟点 `⟳ 数据刷新` 生效。
4. `⟳` 单频道刷新；`🗑` 删除频道（含全部快照，谨慎）。
5. `👥 成员管理`（仅 admin）：查看成员名下/绑定频道、可删。
6. 新增/变更 2 分钟内由 watch 自动抓取并推 R2；daily 凌晨做全量。

## 8. 定时任务与磁盘

```bash
crontab -l   # 查看
# */2 * * * * …/watch-local.sh    每 2 分钟
# 0 3 * * *  …/daily-local.sh     每天 3:00
# 17 * * * * …/fetch-cf-usage.mjs 每小时（用量）
```

* 日志：`logs/watch.log`、`logs/youtube-daily.log`、`logs/cron.log`（20MB 自动轮转）。
* 手动跑：`bash scripts/watch-local.sh` / `bash scripts/daily-local.sh` / `node scripts/fetch-cf-usage.mjs`。
* 全量重传 R2：`bash scripts/upload-r2.sh`（调用 `publish-r2.sh --full`，慢，仅修复用）。
* `backups/`：新 2 份留 raw 秒恢复，其余 gzip，7 份外自动清（含 `.gz`），封顶约 650MB。
* 本机大户（勿动）：`data/`+`web/data/`（写源头）、`node_modules/`（测试/无头）、`.venv`（TikTok 链）、`.git` 2.4G（历史）。可清：npm 缓存（`npm cache clean --force`，约省 1G+，仅拖慢下次全新安装）。

## 9. 发布与部署

* **代码上线**：`git push origin main` → Cloudflare Pages 自动构建（约 1 分钟）。不要推大文件（已 ignore，push 前 `git status` 确认）。
* **数据上线**：cron 自动（watch 增量 / daily 全量末尾）；手动：`bash scripts/publish-r2.sh`。
* **回滚代码**：`git revert` 后 push；**回滚数据**：新备份直接覆盖 `data/`，2 天前的先 `gunzip` 再覆盖，然后手动 `publish-r2.sh`。
* 本地验证 R2 源：`http://127.0.0.1:8000/web/?data=https://pub-a05f40620ff24db7996b638d15240c4c.r2.dev`。

## 10. 密钥与登录续期

* cron 不再依赖 `wrangler login`（OAuth 数小时过期，曾导致 2026-09-24 上传中断数小时）。持久 token 建法：dashboard 头像 → My Profile → API Tokens → Custom（`Workers R2 Storage / Edit` + `Account Analytics / Read`，No expiration），存 `~/.config/social-dashboard/cloudflare-api-token`（600，直贴文件，勿经聊天）。
* 应急：`wrangler login`（弹 Chrome 点 Allow）可临时恢复上传；验证：`wrangler whoami`。
* `gh auth login`：同理（device 码流程）。

## 11. 常见故障

| 现象 | 排查 |
|---|---|
| 页面空、无频道 | 先点 `🌍 全员`；再看是否还在下载 93MB（等 1 分钟）；再查浏览器 Console 是否 CORS 报错 |
| 分组/标签没了 | 确认读的是 R2 源且 `channels.json` 已上传；硬刷 `Cmd+Shift+R` |
| watch 日志 `JSON 校验失败` | 快照写坏或含冲突标记，检查 `data/youtube-history.json` 能否 `JSON.parse`，坏则从 `backups/` 恢复（先 gunzip） |
| `…/node: No such file` | 旧硬编码已修为自动解析；若复现，检查 nvm node 路径是否存在 |
| `Not logged in … non-interactive`（上传全 FAIL） | wrangler OAuth 过期；检查持久 token 文件是否存在且 40+ 字符单行；见 §10 重建 |
| push 被 50MB 警告 | 有大文件混入提交，`git status` 找出并 `git rm --cached` + 补 `.gitignore` |
| R2 403 / CORS 报错 | `wrangler r2 bucket cors list social-dashboard-data` 检查；`r2.dev` 429 限速属正常（换自定义域解决） |
| Pages 构建失败 | 看 dashboard 构建日志；常见为输出目录误配或超 25M 单文件 |
| cron 没跑 | `crontab -l` 确认条目；macOS 看 `logs/cron.log` 有无 tick；`pgrep cron` |
